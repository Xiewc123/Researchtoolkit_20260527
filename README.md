# 使用说明（Usage）

## 简介
本项目是“科研工具箱”前端，基于 Vue 3 + TypeScript + Vite，使用 Element Plus 作为 UI，并通过 Tauri 可选打包为桌面应用。主要面向个人研究/项目/时间管理场景，包含工作台总览、日程、项目、番茄钟、文本转换与历史检索等模块。


## 界面总体说明（快速导航）
- 侧栏（左）：模块导航（工作台总览、日程、项目、文本转换、朝代年号、世界历史），底部工具包括：导入/导出数据、清空全部数据、选择/播放背景音乐、侧栏折叠。
- 主区（右）：各模块的具体页面。


## 模块功能详尽使用说明（界面操作步骤）

1) 工作台总览（Home）
- 作用：显示统计摘要、快捷打卡、专注番茄钟、近期提醒与历史热力图，帮助把握当天与长期进展。
- 快捷打卡：点击“上工”/“下工”记录上班与下班时间，会生成对应时间块并保存到工作台数据。
- 请假：选择请假类型后点击“请假”会生成请假记录与对应时段块。
- 快捷流（主线概览）：页面内的快捷按钮会跳转到相关模块（如日程、项目等）。
- 番茄钟（Pomodoro）：
  - 设置专注/休息时长（可选 25/30/40/50 等），选择关联任务与分类。
  - 点击“开始”启动专注计时；计时结束后自动保存会话并通知（系统通知/弹窗）。
  - 点击“中止”会保存当前片段（若已专注 ≥1min），并停止当前计时。
- 历史热力图：显示过去若干天的专注记录，支持滚动到最新日期。

2) 日程管理（Schedule）
- 作用：管理今日任务、时间块（timeline），快速添加任务并将任务关联到时间块。
- 新增任务：点击“新增任务”或在快速添加输入框输入任务名并回车。
- 任务过滤：可按“今日执行/全部/象限/项目”筛选任务。
- 任务行操作：勾选完成、编辑（打开任务对话框）、删除。
- 时间轴（日程）
  - 选择日期（日期选择器）查看某天时间块；点击“回到今日”跳回今日。
  - 新增时间块：填写开始时间、时长、（可选）关联任务与标题，保存后显示在时间轴。
  - 编辑/删除时间块支持修改关联任务或删除误操作。

3) 项目管理（Project）
- 作用：管理项目集合、项目任务与项目日志、随手记录（笔记）。
- 项目列表：显示项目标题、截止日期、状态（进行中/已完成）。可通过分组筛选（未完成/已完成/全部）。
- 新增/编辑项目：填写名称、截止日期、状态、MD 路径（可用于同步本地笔记）、附件路径。
- 项目选择：点击项目查看项目详情和该项目下的任务列表。
- 任务管理：在项目内可新增、编辑任务，与日程任务字段一致（象限/状态/截止日期等）。
- 项目日志/随手记：在界面右侧或日志窗口中写入日志，可选择关联项目或全局日志，支持编辑与删除。

4) 文本转换（Convert）
- 功能说明：提供繁简转换、基础 OCR 辅助与文本清洗（基于组件描述）。在“文本转换”页面粘贴文本或上传图片，选择转换/OCR 操作后获取结果并复制。

5) 朝代年号表（Dynasty）
- 功能说明：历史朝代与帝王检索工具。输入朝代/年号/皇帝名可检索对应时间、年号信息（便于历史研究与引用）。

6) 世界历史年代图表（History）
- 功能说明：展示文明/帝国的时间轴与并列关系，便于浏览宏观历史跨度与对照。


## 通用工具与数据管理
- 导出数据：侧栏导出按钮会调用 store 的导出方法，优先保存到本地文件（若平台不支持，会触发浏览器下载 JSON）。导出文件名形如 researchtoolkit-data-YYYY-MM-DD.json。
- 导入数据：侧栏导入按钮选择 JSON 文件，导入前会弹出确认提示（导入会替换当前工作台数据，建议先导出备份）。
- 清空数据：会弹出警告确认，确认后清除日程、任务、项目、日志等全部工作台数据（不可恢复，建议先导出）。
- 背景音乐：侧栏可选择本地音频作为背景音乐并播放/暂停（仅前端播放，不会保存到磁盘）。
